# 共享视觉规则

2026-11-02整理，入口为 `rank/src/design-system.css`。保留漫画标题、城市边框色、照片与内容排版；通用操作使用同一套视觉词汇。导出海报的画布样式独立维护。

| 元素 | 规则 |
| --- | --- |
| 主色 | 玫瑰色 `--ui-accent`；主操作使用实色，次操作使用浅底／线框 |
| 文本 | 正文深墨色，说明用 `--ui-muted`；辅助文字12px、控件13px、卡片标题16px作为默认基准 |
| 表面 | 奶油白页面、近白卡片、浅粉选中态；不为每个组件另造一套主色 |
| 圆角 | 通用控件8px、内容卡片12px、弹窗16px；收藏圆形、状态胶囊保留语义形状 |
| 间距 | 优先4／8／12／16px；保持主次操作分组 |
| 状态 | 绿色为营业确认，蓝色为待核线索，浅玫瑰为停止营业；文字标签始终保留，不只靠颜色传达 |
| 交互 | 常用点击区域至少44px；键盘焦点有可见轮廓；主操作不依赖夸张位移与重阴影 |

榜单、地图、QA、更新页均加载共享样式。店铺卡片、官方账号块、展开按钮、收藏、视频入口及行程组件优先复用共享变量。新增组件先使用变量，再按用途保留必要区别；不要用全局规则覆盖城市色、原画或导出画布。

改动后执行发布前自动验收，检查三种宽度、键盘焦点、图集、弹窗和导出；视觉好坏仍需截图人工确认。
