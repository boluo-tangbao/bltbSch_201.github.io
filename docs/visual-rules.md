2026-11-13浏览往返与工具层级：图片卡片在榜单内打开原有按需加载的地点详情，不再先进入地图页；城市入口仍直达原两列图片榜单。普通点击在当前浏览历史中记录卡片的屏幕位置、视图与工具展开状态，返回按钮回退到该历史项，系统返回／前进同样可用；筛选通过链接明确携带，禁用存储时仍能往返。新标签页、直接链接和刷新保留正常链接行为，找不到历史位置时定位对应卡片；搜索链接继续定位命中的店铺／段落。地图与地点目录保留独立入口，旧详情链接继续可用。

榜单标题保留紧凑／舒适切换；对比、导出、分享筛选及开始选店集中到原工具区，手机默认收起，城市与搜索始终可见。地点详情内可对比当前地点；地图首页的对比入口与地图／列表工具同组。未选择地点时，页尾规划与本机行程入口使用普通文档流，不占据固定底栏；工具区也可开始选店。进入详情时保留手机底部“加入清单”，开始选店或已有清单时继续固定展示已选数量与“查看清单”。控制台仅避让实际固定的行程栏。图片、城市框、排序、评价、来源、主题和出发提醒保持原有规则。验收见 `rank/tests/acceptance/browsing-experience.spec.ts`。

2026-11-13主题入口：Day version／Night version集中在控制台“页面风格”区，位于背景音乐上方；按切换区的实际可用宽度自适应，280px及以下隐藏“页面风格”标题和按钮文字，仅显示太阳／月亮图标且不保留标题空白，宽度足够时显示标题、图标与Day／Night文字；图标模式保留按钮名称、悬停提示、选中状态和至少44px点击高度；页头不再占用单独工具行，导出面板只显示所沿用的风格。榜单、地图、QA、更新及路线页共用原ThemeSwitch与主题状态，保留本机记忆、跨页面同步、导出配色及切换时作废旧导出结果的行为。主题切换通过Teleport进入共享控制台，兼容控制台与页头不同的加载顺序；主站尚不支持两套主题的页面不显示空的切换区。

2026-11-12站点识别与手机控制台：主站统一使用“汤包的生活手记”，逛店部分保留“汤包的逛店手记”，署名均为“菠萝汤包scho”。主站六页共用个人主页／逛店榜单／活动记录及各兴趣栏目入口，当前栏目带文字下划线，跨栏目按钮写明目的地；独立城市／地点页同步站点署名及导航用语。`assets/css/site-identity.css` 统一署名层级、44px常用点击区、8px按钮圆角及键盘焦点，主页水蓝与榜单粉色／Night配色保留。

900px及以下控制台收起时使用固定在屏幕右下方的调音滑杆图标与文字入口，向下滚动仍可见；入口采用圆形调音盘、状态灯和文字，待机为柔灰低存在感，鼠标悬停／键盘焦点／按下／展开时亮起主题色、圆盘光晕与状态灯，至少56px点击高度，键盘焦点另用文字双下划线标示。触屏不依赖悬停，点击直接打开；减少动态效果时取消过渡。宽屏侧签也采用灰暗待机、悬停或展开后恢复亮色。存在逛店行程栏时入口上移，避开底部行程按钮及手机安全区域。入口保持在页头的键盘顺序中，视觉位置固定于屏幕；打开后可用面板内“关闭”、Esc或外部点击收起，关闭按钮及Esc返回入口焦点。宽屏继续支持侧签悬停；宽度变化时收起面板并移动同一入口，不复制音频实例或偏好状态。三种宽度下的导航往返、无横向溢出、滚动后入口仍可见且位置不变、行程栏避让、触屏开关、键盘与Night验收见 `site-identity.spec.ts`、`site-console.spec.ts`、`night-theme.spec.ts`。

2026-11-12 Night 阅读与选中态：页面使用更浅的灰绿色深底，卡片与页头分层；城市／标签筛选、视图切换、当前导航、对比选择和清单爱心统一用亮黄绿色底与深色字标识选中，悬停不覆盖选中样式，键盘焦点保留亮色轮廓。页面与导出共用 `themePalette.ts` 色板，Day 配色保持原样。

Night 文字强调色固定使用冰蓝色 `#83cfff`，由共享色板的 `accentText`／`--edition-accent-text` 提供，仅用于短提示、档位名称、图例、展开入口及强调链接；榜单长说明和展开后的解释使用普通正文色，次要备注使用辅助文字色，避免整段着色。亮黄绿色继续用于选中控件底色。页面与导出共用强调色，Day 配色不变。

Night 子界面验收须打开商圈对比表、地图与地点目录、详情日期、分享及行程弹窗、网站控制台，检查固定列、嵌套底板和渐变，并核对文字颜色，不能只检查总榜首屏。三种宽度的回归见 `rank/tests/acceptance/night-theme.spec.ts`；照片、角色原画及档位色标保留本身配色。
