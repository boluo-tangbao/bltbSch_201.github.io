# 共享视觉规则

2026-11-03首页背景：根目录 `akane.png` 为用户提供的原图，网页使用 `images/akane-background.webp` 压缩副本。仅首页通过 `home-page` 类加载固定铺满的图片与浅色蒙层，首屏文字区使用半透明底；手机背景向右侧人物取景。样式在 `assets/css/home.css`，不覆盖其他页面的背景。

2026-11-02整理，入口为 `rank/src/design-system.css`。保留漫画标题、城市边框色、照片与内容排版；通用操作使用同一套视觉词汇。导出海报的画布样式独立维护。

| 元素 | 规则 |
| --- | --- |
| 主色 | 玫瑰色 `--ui-accent`；主操作使用实色，次操作使用浅底／线框 |
| 文本 | 正文深墨色，说明用 `--ui-muted`；辅助文字12px、控件13px、卡片标题16px作为默认基准 |
| 表面 | 奶油白页面、近白卡片、浅粉选中态；不为每个组件另造一套主色 |
| 圆角 | 通用控件8px、内容卡片12px、弹窗16px；收藏圆形、状态胶囊保留语义形状 |
| 间距 | 优先4／8／12／16px；保持主次操作分组 |
| 状态 | 绿色为营业确认，蓝色为待核线索，浅玫瑰为停止营业；文字标签始终保留，不只靠颜色传达 |
| 交互 | 常用点击区域至少44px；键盘焦点有可见轮廓；主操作不依赖夸张位移与重阴影 |

榜单、地图、QA、更新页均加载共享样式。店铺卡片、官方账号块、展开按钮、收藏、视频入口及行程组件优先复用共享变量。新增组件先使用变量，再按用途保留必要区别；不要用全局规则覆盖城市色、原画或导出画布。

2026-11-02手机阅读整理：详情先展示原有短评与标签、当前店单概况及近期快闪提醒；到访／核对／内容更新日期的完整解释和停业迁址记录默认折叠，可展开查看原资料。手机使用素色底与平直标签，保留漫画标题、城市色和角色；侧边导航降为次级样式。底部空清单时提供规划入口，进入地点后可直接加入；已有选择时以“查看清单”为主操作，本机保存／恢复仍由次级入口和清单面板进入，不改变存储与隐私边界。

改动后执行发布前自动验收，检查三种宽度、键盘焦点、图集、弹窗和导出；视觉好坏仍需截图人工确认。

2026-11-03鼠标样式：主站、榜单与独立城市／地点页共用 `assets/css/cursors.css` 和 `assets/cursors/` 的32px小菠萝SVG。普通状态为奶油白箭头，可点击状态为粉色箭头加星光，热点均在箭头尖端(2,2)。仅在精确悬停指针且未开启强制颜色时启用；文本输入、图片缩放、地图拖动等专用状态沿用原指示，不添加跟随层或鼠标移动脚本，图片不支持或加载失败时回退系统鼠标。

2026-11-03商圈实体标签：rank交互页面仅在正文左右的背景留白中放置可掉落、碰撞和抓取的胶囊标签。标签不展示玩法说明文字，字形优先使用幼圆／圆体，常规字重和柔和灰紫色；缺少系统圆体时沿用本地卡通字体。标签为固定背景层，完全不占文档流，不新增页头高度，不缩窄或移动榜单。侧边范围按当前正文实际边界和内边距计算，与正文边框、阴影及页底清单保留间隔。名称和详情链接来自已公开地点；颜色直接读取 `utils/model.ts` 的对应档位，使用该色系的柔和浅底与边框，不另设随机调色盘。候选批次均衡覆盖现有档位，“再掉一次”轮换更多地点，不改榜单排名。左右任一侧可用宽度不足88px或可用高度不足260px时完全隐藏且不加载物理模块，优先保留首屏榜单；窗口放大到有足够留白时恢复。较长胶囊侧转以适应边栏，不裁掉名称。玩耍区域独立于正文、搜索和底部清单；真实拖动或长按松手不导航，轻点及键盘Enter打开对应详情。

物理模块按需加载，停稳后停止逐帧计算，拥挤堆叠的微小抖动也有计算时限；抓取后重新唤醒，隐藏页面时暂停，收起和卸载时清理。仅在当前标签页记住收起偏好。系统“减少动态效果”时不加载物理模块，展示可换批次和点击的静态标签；模块加载失败同样保留静态链接。指针取消、视口变化和收起时释放抓取状态。组件为 `FallingPlaceTags.vue`，物理逻辑为 `utils/tagPhysics.ts`；侧边边界、首屏位置、拖拽与响应式检查在 `tests/acceptance/place-tags.spec.ts`。

2026-11-03浏览入口整理：图片总榜标题旁始终显示紧凑／舒适切换，手机无需展开筛选工具；默认紧凑并沿用浏览器所存偏好。800px及以下打开具体地点时默认收起上方地图与筛选、地点目录，在详情顶部可展开；详情按需加载完成后重新定位，带搜索目标的链接由原搜索逻辑定位店铺／段落。电脑地图布局保持原有行为。

2026-11-03出发提醒：移入原生模态弹窗，每个地点首次进入自动展示；确认或Esc收起后记住当前提醒摘要，摘要变化后下次进入再提示。只在浏览器保存公开摘要及地点ID，不写入行程信息；存储不可用时保留本页面内存回退。详情保留44px可点击的文字入口，弹窗可重新查看、跳转店单或具体店铺，关闭先释放滚动锁再定位。原5条递增、历史默认收起及日期判断规则不变。

地点标签下放为独立“标签”章节，位于介绍后、店单前；顶部和侧边章节导航共用同一锚点。首屏短评区不再重复标签。标签搜索命中定位具体标签，保留现有详情URL及find参数；店名、正文等其他命中规则不变。
