| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

未知图片、日期、位置可填 null，详情可暂空；内容更新日期和评级由作者填写。城市颜色在 site.json 中固定。维护更新记录时使用不变的店铺 ID。
