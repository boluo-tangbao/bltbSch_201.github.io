# Coser 集邮合影的自然精修方法

这套方法用于漫展真人合影。用照片本身做局部后期，保留每个人的五官、脸型、表情、肤色，以及原有的妆造和发型。全程使用原片像素，不使用生成式填充、重画、液化或换脸。

## 从哪一版开始

新照片从归档原件开始。先按现场光轻调白平衡和曝光，兼顾脸部阴影与服装高光。粉紫色伞光、舞台灯光等属于现场氛围，适量保留。逐张检查连拍里的脸和头发位置。已有用户认可的人脸精修版时，以它作为顺发底图，避免叠加磨皮和调色。

## 人脸与妆容

- 给每位合影者的可见面部分别做柔边选区，避开眼镜、口罩、头套和背景人物。
- 在额头、鼻尖和颧骨局部压低过亮的反光，保留鼻梁和面颊的明暗起伏。淡化明显斑点、干纹和卡粉时，参考周围皮肤，保留毛孔和细小肌纹。用修前后对照检查肤色，避免整脸变白、变粉。
- 顺着已有的眼线、睫毛和唇色轻补对比与色彩，保留美瞳、原来的唇线和露出的牙齿。
- 本组浅蓝发、荧光黄领口的 coser 有单独的去胡茬要求。只在上唇、嘴角和下巴减淡深色胡茬及青影，参考本人邻近面颊的肤色，保护鼻孔、人中和嘴唇边界。这一步按人指定。

## 顺发

1. 对着原片圈出需要梳顺的发束，沿刘海、鬓发和发尾分别收边。绕开皮肤、眉眼、帽沿、发饰、手指及背景。短发和卷发分成较小区域，保留外轮廓、卷度和发尾碎发。
2. 根据每一小片头发原有的纹理判断走向，只沿该方向取邻近像素做轻度平滑。给颜色或亮度相差较大的邻点较低权重，让横向毛躁变轻，同时保留相邻发束的分界。
3. 与原图混合。已确认的浅蓝直发样片在选区内部最多混入约 63% 的顺发结果，边缘逐渐减弱。根据发束宽度、照片尺寸和卷曲程度调整取样距离；细卷和短发可降低强度。顺发这一步沿用底图色光。

## 导出与检查

按原文件名、原像素尺寸另存到新目录，保留原件和已确认的版本。逐张核对文件和尺寸。用相同位置、相同比例对照修前修后，重点看眼妆、唇线、刘海末端、帽沿和发饰交界，再缩小检查整张合影。发现串色或发束被糊成一片时，缩小选区或降低混合强度。
