# 日本旅行素材与发布

## 当前入口与组织

日本旅行使用 japan-travel.html，首页按城市分组，城市内是作品巡礼或普通旅行主题记录，记录内部按片区／地点显示图片。搜索覆盖城市、作品标签、片区、说明、图片标题及原文件名。MyGO 与 Ave Mujica 在东京合并为一条巡礼记录，按六个片区分段。

旧 pilgrimage.html 的正式入口转到日本旅行记录页；?demo=1 保留早期虚构功能演示，用于兼容已有演示链接，不混入真实记录。早期 assets/data/pilgrimage.json 及对应数据模型仅供该旧演示原型使用，当前真实清单位于 assets/generated/japan-travel/manifest.json。

## 原素材与清单

原素材保存在 content/pilgrimage/2026-8：东京/ 下，用户提供的文件名、原图和说明均保留。content/pilgrimage/records.json 是本轮稳定城市 ID、记录 ID、分组目录与出处的配置。日期依据用户的圣地巡礼补充.txt：2026-08-13 至 2026-08-21，仅记录行程范围，不为地点分配虚构日期。

本轮为4个城市分组、11组主题记录、102张图。镰仓分组沿用用户行程范围，涵盖其藤泽与江之岛照片；不将行程分组误当行政区归属。空的横滨目录不生成空卡片。

## 本批不压缩（2026-11-16 用户明确要求）

本批图按用户要求保留原尺寸、原质量。prepare-japan-travel.mjs 直接复制源文件，按内容 SHA-256 命名，核对发布副本与原文件哈希；不调用图片编码、缩放或裁切。Sharp 只读取图片尺寸。已拼好的作品／现实对照图完整展示，部分单张实拍也按原图展示，不重复拼接。

列表封面由浏览器取景显示，源文件不改变。正文图片进入可视区域附近才请求；超过3200万像素的两张原尺寸大图不在列表自动解码，查看器提供原图直达入口。其他图片可放大、前后切换、键盘操作和新页查看原尺寸。

此项是本批旅行照片的明确例外，其他新增媒体仍遵循原预览规则。没有完成“仓库只保存压缩网页素材”的迁移，不调整现有原件跟踪政策。

## 提交与云端构建

用户提交原素材目录（包括来源与说明）、records.json、页面与脚本等源文件。assets/generated/ 和 _site/ 继续忽略提交。云端的 assemble-site.mjs 自动执行 prepareJapanTravel，从仓库原图构建发布副本；站点包不会复制 content/ 本身，也不公开原始说明文件。

请勿只提交页面而漏掉未跟踪的原素材目录。图像缺失、空分组、重复登记或行程内存在尚未登记的图片，生成脚本均明确报错。仅清理脚本管理的失效发布副本，原素材不删除。

## 来源与验收

用户确认现实照片均为本人拍摄；动画画面来自 Anitabi Map 和作者手动截图。页面按该批次统一标注两类来源，不伪称逐张来源已确定，不补造集数、时间点或坐标。春物地点别名说明、池袋305路等用户确认内容保留并用于搜索。

验证包含原图与发布副本逐张字节／SHA-256 一致、全部图片登记覆盖、城市／作品／地点检索、移动端两列、深链接、刷新／后退、放大、超大图入口、来源展示和最终发布目录引用检查。命令：node scripts/prepare-japan-travel.mjs；node --test rank/tests/japan-travel.test.mjs；node scripts/verify-pilgrimage.mjs --published。
