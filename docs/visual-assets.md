# 页面素材说明

## 素材归档与重构目标（2026-11-09）

用户确认将以下方案作为以后重构网站的目标，优先保证访客的阅读体验与长期维护。此次只记录规则，尚未迁移目录、修改忽略规则或切换构建流程。保留现有网站可以实现此方案，重做界面不作为前置条件。

### 保存与上传范围

| 素材 | 原件保存 | GitHub 与网站使用 |
| --- | --- | --- |
| 原始照片 | 本地归档，另做硬盘或云端备份 | 默认不上传原件，提交压缩后的高清查看图及缩略图 |
| 原始视频 | 本地归档，另做独立备份 | 不上传原件；需要站内播放时提交压缩播放版和封面图 |
| 改用 B 站的视频 | 本地原件按归档规则保存 | 保存 BV 号和有出处的封面，不重复上传站内播放版 |
| 图片出处、拍摄／读取日期、关联信息 | 与素材一同保留 | 继续提交必要的来源和元数据，保持作者实拍与网图区分 |

“仅上传网页版本”包括高清查看图，不是只上传低清小图。源码、配置与正文仍正常提交；该规则针对照片、视频原件与网页衍生素材的分工。

### 阅读体验要求

- 列表使用按设备尺寸选择的缩略图；首屏关键图片优先，其余按需加载。点击照片后再加载高清查看图，保持现有来源、说明与日期。
- 活动采用 480px 缩略图／1600px 查看图，商圈采用 160／320／640px 预览及 1280px 查看图作为现行基线。店单、楼层图、海报等文字密集图片必须检查小字可读性；必要时提供更高分辨率的按需查看版本，不机械套用统一尺寸或压缩率。
- 视频先显示封面，用户点击后再加载站内视频或 B 站播放器；提供清楚的播放入口与失败后的直达链接。只有 B 站链接的活动也必须有封面，封面不计入现场照片。
- 重构保留稳定地点／活动 ID、旧分享地址和内容关联。原“打开原图”入口须逐项迁移：有真实公开原件时才保留该名称；否则改为“查看高清图”，不能指向仅本机可访问的原件或失效 GitHub 链接。

### 迁移步骤与验收

1. 先清点原件与引用，建立原件、网页版本及地点／活动之间可核对的对应关系；记录内容指纹、必要的来源和日期。验证独立备份可读取，原件迁移前后字节一致。
2. 本地新增素材时先归档原件，生成或更新网页图片、压缩视频与封面，检查质量及全部引用。未变素材复用，更新后使用内容指纹避免旧缓存。
3. 明确网页素材及必要索引的提交目录，再同步改造生成脚本、运行时引用、`.gitignore`、清理脚本和云端工作流。迁移后原件目录忽略上传，网站依赖的网页素材及必要清单必须纳入版本管理；不能仍将唯一网页素材当作可随时删除的缓存。
4. 云端只验证、组装和发布仓库内的网页素材；不依赖本机原件、不通过旧提交下载原图，也不在构建时联网获取 B 站封面。缺失素材明确报错。
5. 使用不含本地归档与生成缓存的全新检出完成构建、发布资源检查，并验收手机／桌面的列表、放大阅读、视频播放、旧链接及导出。原件不进入发布包，网页素材不存在断链，发布体积满足项目预算。
6. 验收通过后再从当前 Git 跟踪中移除已归档原件，确保本地归档仍在。加入 `.gitignore` 不会自动取消已跟踪文件，也不会清除历史版本；历史清理、强制推送或重建远端仓库属于独立操作，需用户明确授权。迁移本身不要求更换仓库、站点地址或域名。

迁移完成前继续遵循当前构建流程，不提前忽略 `content/activities/` 或 `rank/public/images/places/`。目前活动与商圈预览仍在本地／云端自动生成且被忽略提交，部分原图仍随仓库保存；已有 `.local-media/` 视频备份只在本地。这些现状与上面的重构目标须明确区分。

网站体积或访问量持续增长时，再评估独立图片存储和 CDN，按主要访客所在地实测加载速度、费用与可维护性；不因这份规则自动新增服务、迁移托管或产生费用。

## 媒体预览固定规则（2026-11-09）

- 适用于以后新增及替换的图片、视频封面、角色与地图备份。原图保留；展示图片由既有生成脚本自动产生，禁止只添加原图而绕过生成／验收，也不要手改生成目录。
- 活动图片与视频封面：生成最长边不超过 480px 的列表小图及 1600px 的查看图，保持比例，不放大小图；列表只加载小图，点击后加载查看图或视频。
- 商圈封面、图集、独立视频封面及地图备份：自动生成 160／320／640px WebP 预览与 1280px 查看图，复用已有生成流程；角色继续使用专门的缩略图流程，像素头像保持原分辨率。
- 只有 B 站链接、没有现场媒体的活动也须有预览图。将真实视频封面保存到活动的 `preview/` 子目录，用 `previewImage` 指定并记录出处；封面不计入现场照片数量。构建不访问 B 站，避免外站不可用导致封面失效。
- 用户明确指定以 B 站替代的视频，活动只引用指定 BV 号，移除对应站内视频副本并重新生成清单；照片保留，原件归档保持本地保存，未经要求不重写 Git 历史。
- 发布前运行素材生成、完整构建、发布引用检查和活动验收；封面、缩略图或查看图缺失必须修复后再发布。

## 既有素材说明

角色原图保存在 `rank/public/images/official/`，来源页、原始图片 URL 与半身取景参数保存在 `character-art-sources.json`。这些图片没有 AI 重绘：网页通过 CSS 取景保留原来的线条、表情与服装。官方设定组合图只展示正面人物区域；黑川茜使用 J:COM 声优访谈中的授权动画画面，远坂凛、由比滨结衣使用官方角色页中的动画画面。相关链接也显示在页面的角色介绍里。

主网站「我的动画老婆们」使用原画半身取景，不包含初音未来和 DeepSeek 娘。`/rank/`、地图与建议页使用已有的像素人物；DeepSeek 娘保留现有的社区拟人像素图，不标注为官方角色设定。

所有页面的站点页脚不放置像素人物。

图片总榜与地图页直接点击人物即可轮换目前保留的 22 位角色，所有像素人物默认侧脸，切换到另一人物时重新显示侧脸。黑川茜、小野寺小咲、一之濑帆波、潮留美海同时使用现有的正脸 v2 和侧脸 v3 素材，悬浮介绍内提供「换个角度」。键盘聚焦或触屏点击也能查看介绍和角度选项。QA 页的 DeepSeek 娘按卡片宽度缩放为 80–160 像素。

主网站四张封面为真实照片，统一压缩为 960×640 WebP；非二次元页面不使用 AI 生成图片：

- 体育：[Peter Glaser 的足球照片](https://commons.wikimedia.org/wiki/File:Adidas_soccer_ball_on_a_grass_pitch_(Unsplash).jpg)，CC0。
- 文艺：[Vanessa David 的钢琴照片](https://commons.wikimedia.org/wiki/File:Grand_piano_with_music.jpg)，[CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)，进行封面取景和缩放，作者与许可链接同时显示在页面。
- 动漫：复用本仓库苏州相城天街手记的 `photo-03.webp`，玩聚猫店面。
- 旅行：复用同一手记的 `photo-01.webp`，相城天街外观。

官方角色素材版权归各作品权利人所有；出处链接不表示取得额外的版权授权。

店铺图集的选材、官方账号原始笔记及坐标依据统一见 [店铺与素材来源](research-sources.md)；角色原画的来源 JSON 保持独立，供代码读取。

加载优化：构建时为像素头像生成保持原分辨率和透明轮廓的近无损 WebP，避免有损压缩让像素边缘模糊；主页角色卡片使用 640px WebP 缩略图，点击后才请求原画。店铺图集放大时先使用 1280px 图片，原图通过单独入口打开。在线播放视频使用 H.264/AAC、最长边 1280px 的副本，并将 MP4 索引前置（faststart）；点击视频封面后才加载，原视频仍有单独入口。衍生素材使用内容哈希命名，构建时复用，源文件变化后自动更新。地图和 QA 首屏人物在 HTML 中提前加载，其余人物保持按需加载，悬浮时仅预取下一位；开启省流量模式时不预取。
