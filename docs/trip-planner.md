# 逛店行程

2026-11-13当前用语统一为“想逛清单”“开始选店”“加入清单／已加入”；下文带日期的记录保留当时的操作背景，现行名称以[共享视觉规则](visual-rules.md)为准。

图片榜单与地图找店共用想逛清单。相同商圈的地点、常规店和快闪活动合并为一站；店名、楼层、来源核对时间和档期沿用生产数据。搜索和选择仅使用公开地点与确认营业的店单，活动仍按日期自动排除已结束记录，不把待核、停止营业或到期主题恢复为在营。

## 访客操作

- 2026-11-01调整选店入口：普通浏览时隐藏地点卡片、地点标题与具体店铺旁的添加控件，只保留统一的“规划逛店”入口。主动进入选店模式后显示“想逛／已选”，底栏提示选店与已选站数；选好后退出模式并打开行程。已有清单可“继续选店”。模式和清单一起在当前标签页内跨榜单／介绍页面保留，不改变店单营业或来源数据。
- 同日更新样式：榜单选店入口为照片右上角的小圆形心形按钮（32像素底色、15像素图标），详情页入口随标题同行，具体店铺改为右上角无底色心形，与纠错图标并列，不再在卡片底部单列胶囊按钮；选中后心形填色并更新读屏状态，保留44像素点击区域和键盘焦点。底栏统一提示点心形加入清单。
- 首次打开展开第一站；其他站只显示编号和商圈名。点击列表或地图切换当前站。
- 从当前站打开榜单选择，范围中心保持固定，只查同城。默认3公里，依次扩大到5公里、全城；商圈和具体店铺都按双列展示，选店时聚焦当前商圈。
- 商圈内补店锁定所属商圈，独立地点须填写城市、地址。自填内容标记为个人记录，仅进入本次行程、复制文本和导出文件，不写入网站店单或营业确认。
- 通知作者生成可编辑草稿，提供复制和 B站主页入口；访客自行粘贴发送。网页不发送后台消息。
- 交通选择默认取百度地图返回的可用最快方案，地图旁与下方列表同步。通勤总数不含逛店停留，未来到达时间包含访客设置的预计停留；第一站视为出发点。
- 完成第 N 段会完成之前各段。已完成的站点和当前出发点固定；从新读取的系统时间计算剩余路线。刷新、重新打开清单也读取系统时间，进度保留在当前标签页的 sessionStorage。可单独重置进度。

## 数据与真实路线

`rank/scripts/prepare-trip-nearby.mjs` 从 `places.json` 的公开 WGS84 坐标生成 `trip-nearby.json`，在开发启动和构建前运行。3／5公里的成员资格使用未取整的球面直线距离判断，展示米数取整；无坐标地点仅在全城列表展示。线上搜索只读取索引，不重复计算距离。新增地点或修改坐标后重新生成；不能把这些直线距离当作实际通勤距离。

商场关门参考单独维护在 `rank/src/data/mall-hours.json`，不改写店单营业状态、原来源和核对日期。2026-10-31检索后，南京路百联ZX、静安大悦城、美罗城、环球港采用有明确原文的官方／文旅介绍（均22:00），保留链接、原文、原页日期与实际读取日。美罗城、南京路百联的原页为2024年的介绍，标为公开参考，不作为逐店当日确认。静安文旅页的页眉日期不冒充发表日期。

其他商场尚未找到足够明确、无冲突的日常公告，按用户2026-10-31提供的21:00、五角场百联与南方百联22:00暂作规划参考，前台明确标待核。第一百货地图结果同时有全周22:00及周一至周四21:30／周五至周日22:00，先不据此覆盖暂用参考；其他分店、餐饮／影院延时、快闪和节假日时段不套用于商场谷店。外文书店、悦沢书店、少女乐队乐器店、北京路步行街与自填独立地点没有统一商场时间，不填默认值。本轮为商场日常时间专项检索，不将其称为逐店账号研究完成。

访客填写“本次截止”优先于商场参考；只改停留不固化商场默认值，可恢复商场参考，个人覆盖只存当前标签页。没有访客自填截止的站点，预计到达或逛店跨过20:00时提示“部分店可能提前收店”；这是潜在风险，不声称店铺实际20:00闭店。优化先减少超过参考截止的站数和延误，再减少该提醒的站数，最后比较通勤。第一站视作当前出发点，不含第一站逛店停留。跨午夜后的到达仍比较出发当天截止，不自动推断次日开门。

`baiduTripRoutes.ts` 复用现有百度浏览器端 AK / 代理配置，使用 WalkingRoute、TransitRoute、DrivingRoute 的秒数和道路路径。浏览器端无须新增服务端 Key 或访客登录。数值来自真实方案，不使用直线距离除速度来填充。JS API 返回当前估时，不提供此实现中的预约出发预测；后续公交时段、路况和候车仍需现场确认。

查询最多2个并发，成功方案缓存3分钟；刷新页面重新查询，点击完成或手动重新计算会跳过缓存。支持取消旧查询，旧回调不会覆盖新行程。连续失败会暂停；缺一段则完整总数为空，仅显示已知部分。地图加载或鉴权失败时保留名单与外部导航。

8站以内固定首站／已完成前缀，比较剩余有向地点对的可用交通方案，再枚举顺序，优先减少超过参考截止的风险、延误，再减少20:00提前收店提醒，最后比较总通勤。存在缺失方案时保留原顺序；超过8站只查询当前逐段路线。建议基于本次实际返回的方案，不宣称覆盖地图服务未返回的方式，也不代表未来交通条件的全局最优。

## 验证

`npm test` 包含附近索引、分组、自填记录读写与导出转义、缺失路段、闭店窗口、已完成前缀和百度方案解析／缓存／取消测试。`npm run build` 包含数据校验、TypeScript检查和生产构建。界面验证覆盖真实上海店单、弹窗锁定、私信草稿、双列、单站展开、手机边界、刷新进度及时间。

本地百度 AK 可能因 Referer 白名单拒绝预览地址，不能为测试放宽正式 AK 的来源限制；应在正式域名复核服务，不把模拟方案混入生产代码。
