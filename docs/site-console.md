# 全站随身控制台

普通页面、榜单的五个入口及生成的城市／地点介绍页共用 `assets/js/site-console.js` 与 `assets/css/site-console.css`。右侧渐变竖向“控制台”标签展开贴边侧栏，展开时标签随侧栏移至左侧边缘；鼠标悬停侧签展开，移出侧签及侧栏整体区域后收起（140ms短暂缓冲避免滑动过程中误收起），没有关闭按钮。触屏设备点击侧签切换，键盘可用 Enter／空格展开、Esc 收起；焦点移出侧栏或点击外部也会收起。悬停不抢占键盘焦点。侧栏关闭后内容使用 inert 与 aria-hidden 禁用聚焦／读屏，不阻挡正文操作。个人主页与逛店榜单以粉桃／蓝紫渐变中文卡片置于侧栏顶部；侧栏文案使用中文，不显示英文眉题和装饰图标，保留顶部两个入口的跳转箭头；操作按钮使用中文，不设置“继续探索”分区。关闭面板不暂停音乐，打印时隐藏。点击星光开关控制主站原有特效，菠萝鼠标开关控制已有鼠标样式；偏好在同源页面间保存。系统要求减少动态效果时，不播放唱片旋转或点击星光。

## 添加网站歌单

把可公开使用的音频放在 `assets/music/`，编辑同目录的 `playlist.json`。路径相对网站根目录，兼容根域与仓库子路径部署；文件名建议使用英文。示例（将示例文件名替换为实际文件）：

```json
[
  { "title": "第一首歌", "src": "assets/music/first-song.mp3" },
  { "title": "第二首歌", "src": "assets/music/second-song.m4a" }
]
```

尚未收到音频，所以目前配置为空数组，不包含示例曲目或失效链接。歌单按配置顺序播放，最后一首后回到第一首；单曲播完后停止。支持播放／暂停、上下首、进度跳转、音量和展开歌单选曲。选曲／上下首沿用当前播放或暂停状态。

访客首次需点击播放。音量、星光和鼠标偏好，以及网站歌曲路径和播放进度保存在浏览器本地；存储不可用时仍可使用。每个标签页独立播放。选择本机音乐仅用于当前页面试听，不上传，不持久保存文件或文件名，刷新／跨文档跳转后需重新选择。

榜单内部无需重新加载的导航与关闭面板会继续播放；主站跨 HTML 页面、主站与榜单互跳会停止，网站歌单在新页面恢复进度后需点击继续。完全无缝跨页播放需要把这些页面改为统一应用外壳，不能仅靠保存进度完成。
