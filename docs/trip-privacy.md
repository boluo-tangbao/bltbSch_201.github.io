# 行程隐私与本机保存

2026-11-02用户授权试做行程保存，并要求访客信息不能被轻易调用。本功能仅在当前设备、当前浏览器保存，不新增账号、后端数据库、上传接口、公开查询接口或行程分享链接。

## 保存与恢复

- 未保存的公开地点／店名选择暂存在当前标签页的 `sessionStorage`；关闭标签页后清空。自填地址、备注与自填店名只在当前页面内存中使用，不写入普通浏览器存储；旧版会话中的自填条目在读取时清除。刷新或总榜／地图跨页面切换前需要加密保存，否则自填条目不会恢复。
- “本机行程”位于空清单时的页面底部；已有清单可从“整理与导出”内的“保存／恢复行程”进入。需要主动设置独立口令，12—128个字符，建议使用足够长、未用于其他账号的口令。
- 名称、选择顺序、自填信息、停留时长及手填截止／交通偏好一起加密。最多20个行程、每个120项；保存的是选择和设置，不存地图轨迹、通勤缓存、精确实时位置或访问历史。
- 原计划恢复前显示已结束快闪、停业、移除／更名等缺口；原存档保留。恢复会替换当前临时清单；不可用项在“原计划中需调整”单列，不进入路线、复制和当前HTML清单。重排可用地点时也不丢弃这些记录。
- 恢复时重置出发时间、完成进度与交通估算，不把上次时间／交通方案冒充当前结果；地图查询默认关闭，必须主动点击“启用地图与通勤查询”。
- 可下载整个保存区的加密JSON备份，在另一设备打开本站、设置本机口令后导入。备份使用原保存区口令解锁，预览后才添加；新分配ID，不覆盖同名或已有行程。支持本机行程重命名／删除；删除需要第二次明确点击。
- 多个标签页写入前比较原加密存档，发现变化就拒绝覆盖，提示重新解锁。达到存储配额或浏览器禁止存储时直接提示失败，不降级成明文。

## 加密和输入边界

- 使用浏览器 Web Crypto：AES-256-GCM，128位认证标签；每次写入随机生成96位IV。每个保存区使用随机128位盐，PBKDF2-HMAC-SHA-256、600000轮从口令派生不可导出的密钥。算法、格式版本及迭代参数受限，作为附加认证数据绑定，不接受文件指定任意算法或巨大迭代数。
- `localStorage` 的 `tangbao-trip-archive-encrypted-v1` 及备份文件只保存格式版本、参数、盐、IV和密文；名称、地址、备注、口令和密钥不以明文存入存档。不把“Base64编码”当作加密。
- 口令输入处理后清空，不保存、不自动解锁、不上传。关闭保存窗口、页面进入后台或闲置5分钟，会释放保存区解密数据和密钥引用，并撤销备份对象URL；恢复后的本次清单仍保持可见。
- 导入前限制文件不超过2MiB，严格检查版本、参数、编码、行程／条目数量、字符串长度及必要字段。偏好按白名单重建，拒绝原型键；输入只以文本显示，不执行HTML、脚本或文件内URL，不加载文件指定资源。
- HTML清单及复制结果是访客主动导出的明文，可能包含自填地址和备注；界面提醒谨慎转发。加密备份也应妥善保管，口令遗失无法找回，清理浏览器数据会删除本机保存。

实现依据：[MDN AES-GCM参数](https://developer.mozilla.org/en-US/docs/Web/API/AesGcmParams)、[MDN Web Crypto加密接口](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt)、[OWASP PBKDF2参数](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2)。这里借鉴PBKDF2工作因子，不宣称网站符合特定认证标准。

## 保护范围与第三方服务

加密保护已保存存档的静态内容，减少同一浏览器、同一站点源的其他页面或脚本直接读取存储就获得明文的风险；它不能防御弱口令离线猜测、恶意浏览器扩展、设备失陷、键盘记录或在解锁时执行的恶意同源脚本。本站原有统计、地图等第三方脚本也属于运行时信任边界，不能因此宣称端到端隔离、绝对私密或“任何脚本都无法调用”。浏览器的同源存储边界是域名源，不是 `/rank/` 路径。

保存／解锁／导入／恢复逻辑没有网络调用、日志上报或剪贴板读取。主动启用行程地图与通勤查询后，百度地图会收到需要定位／查询的地点、自填地址和城市；备注不发送，自填地址不进入持久地理编码缓存。主动打开外部导航同样会把目标地址交给地图服务。作者收录通知仍需访客主动复制并前往B站发送，不自动提交。

共用设备使用结束后，应关闭保存窗口、清空本次清单；不打算保留时删除全部本机行程，并自行删除下载过的明文／加密文件。

## 验证

`tests/trip-archive.test.mjs` 检查加密往返、非导出密钥、随机盐／IV、错误口令、篡改密文、文件／数量上限、参数白名单、原型键及状态复核。

`tests/acceptance/trip-archive.spec.ts` 在本地副本检查保存、关闭后锁定、新标签页恢复、偏好恢复、备份下载／导入、删除、闲置锁定、并发覆盖保护、不可用项目保留与纯文本显示。捕获所有标签页请求，断言测试口令、自填地址、备注和行程名不进入URL或请求体；检查普通浏览器存储中没有这些私有标记，地图启用前不载入地图脚本。验收拦截外部请求，不上传真实访客信息、不污染访问统计。
