# 图片总榜、地图与视频介绍

采用已确认的结构：

- 图片总榜：`/jimmyGu.github.io/rank/`
- 地图与地点目录：`/jimmyGu.github.io/rank/guide/`
- 单个介绍：`/jimmyGu.github.io/rank/guide/#/place/条目ID`

`guide/` 是单独生成的静态 HTML 入口，可以独立访问和刷新。详情使用 hash 路由，适配 GitHub Pages。第一版的 `/rank/#/place/条目ID` 链接继续有效。

## 图片总榜

五档仍为夯、顶级、人上人、NPC、拉完了。档位色条表达推荐度；**图片外框颜色表达城市**。默认不铺开名称、短评和日期，点击图片进入介绍。悬停或键盘聚焦时显示名称；手机可勾选“显示名称与城市”。名称始终保留在无障碍标签中。

城市颜色在 `rank/src/data/site.json` 中集中配置，例如：

```json
"cityColors": {
  "上海": "#b95b43",
  "广州": "#507ba2"
}
```

这里只是配色填写示例，未在正式榜单中添加城市或店铺。新发布城市必须配置唯一的六位十六进制颜色。不要为了调换排序而改变颜色；图片边框、城市图例、地图标记、详情和导出文件共用这份映射。

## 地图与导航

每个条目可追加 `location`，不确定位置时填 `null` 或不填：

```json
"location": null
```

有经过确认的坐标后，使用以下结构（用真实值替换占位文字）：

```text
location: {
  lat: 纬度数字,
  lng: 经度数字,
  coordinateSystem: "wgs84",
  address: "准确地址"
}
```

必须是 **WGS84**。如果手头来自高德/腾讯/百度的坐标，不要直接改坐标系标签；先确认和转换坐标，否则会偏移。没有坐标也能进入目录与视频介绍，只是不生成地图标记和导航按钮。

地图采用 Leaflet + OpenStreetMap，点击“加载互动地图”才请求底图，保留地图来源署名。地图标记和目录可打开同一个介绍；城市/关键词筛选同时作用于地图和目录。底图网络失败时会提供重试，目录与外部导航仍可用。测试使用本地模拟瓦片验证交互与失败恢复，未声称所有地区网络都能访问底图。

手机和平板可切换“地图 / 地点目录”，桌面同时显示。三个设备访问的是同一套已发布内容；不涉及登录账号或设备间同步私人草稿。实际出行点击“去这里 · 高德地图”，移动端尝试唤起 App，另有网页版地图入口。App 能否唤起取决于设备、安装情况和浏览器，不强制跳转、不主动读取当前位置。

资料：[Leaflet 官方指南](https://leafletjs.com/examples/quick-start/)、[OpenStreetMap 瓦片使用要求](https://operations.osmfoundation.org/policies/tiles/)、[高德 URI 地点标注](https://lbs.amap.com/api/uri-api/guide/mobile-web/point)。

## 视频介绍优先，图文逐步补充

每个条目可追加 `video`。没有视频先保持 `null`；提供原视频链接、文字节选和片段起止时间后再录入：

```json
"video": {
  "url": "https://example.com/replace-with-your-video",
  "title": "填写你的原视频标题",
  "excerpt": "粘贴你自己的视频介绍原文；换段用 \n。",
  "startSeconds": 63,
  "endSeconds": 95,
  "clip": null
}
```

这个链接是占位示例，不能原样发布。时间是**原视频中的片段范围**，页面显示为 `1:03–1:35`；普通外链不会假装已经自动定位或剪辑。可只提供链接与文字，时间未记录时省略时间字段。

如有已经剪好的 MP4/WebM，将文件放到 `rank/public/videos/places/`，例如 `my-place-intro.mp4`，设置 `"clip": "videos/places/my-place-intro.mp4"`。站内播放器直接播放该片段，支持手机内联播放，不自动播放。片段应在上传前剪好，`startSeconds/endSeconds` 只记录原视频出处，不会替你裁切上传的文件。视频较大时建议使用原视频链接，避免把长视频放进 Git 仓库。视频加载失败会保留原视频入口。

详情页顺序：名称和一句话结论 → 视频/文字节选 → 位置与导航 → 后续图文。`details`、`pros`、`cons`、`gallery` 继续可用，图文可慢慢补齐。

## 导出完整内容

总榜“导出榜单”提供：

1. 简洁排序图 PNG：图片、城市、名称、档位、原排名与城市色框。
2. 短评长图 PNG：再加一句话评价，自动按完整卡片行分页。
3. 完整内容 HTML：保留全部已选条目的文字、封面和图库、视频节选和出处时间、来源链接、位置导航、评价标准和对应更新记录。

默认导出当前筛选，也可选择完整榜单。HTML 的图片直接嵌入文件，可离线阅读，也可用浏览器“打印 → 另存为 PDF”；**视频文件和地图底图不打包**，观看视频和导航需要联网。未发布的条目及对应记录不会导出。

## 后续提供内容的最简方式

给出：城市、店名、档位、同档顺序、识别用图片、原视频链接及片段范围、视频介绍文字、准确地址或地图位置。暂时不清楚的图片、视频、位置可以后补，不编造到访或观点。

当前正式条目和更新记录仍为空数组。这一版完成页面和内容结构；实际地点、地图标记、视频片段要在你提供素材后出现。
