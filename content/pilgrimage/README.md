# 巡礼素材接收

按一次旅行、城市与大概地点分组，保留原照片文件名。正式记录由 Agent 整理到 assets/data/pilgrimage.json；本目录不会仅因放入照片就自动发布。

建议结构：

    content/pilgrimage/
      旅行名称（可选）/
        城市—大概地点/
          原照片.jpg
          原照片2.jpg
          说明.txt
          作品截图/（有参考画面时才需要）

说明.txt 写关联作品、城市、大概地点、一两句说明即可；到访日期知道就写，不确定保留原文。例：

    作品：填写一部或多部作品
    城市：填写城市名
    地点：某车站附近／某条街／某座桥一带
    日期：有记录就写，没有可省略
    说明：这里写自己的感想，或者这组照片大概拍了什么。

允许只记大概区域，不要求经纬度、具体门牌或截图对位。同一地点关联多部作品时，只放一份照片，在作品栏列出作品名称。多次到访可在地点下按已知日期或“第一次／第二次”分子文件夹，并分别写说明。

作品截图与本人实拍分开放，参考画面尽量附出处；没有参考画面时先展示巡礼图集，不必凑对照。原件保持本地原样；由 Agent 接入生成 480px 缩略图和 1600px 查看图的流程、检查质量与引用后再发布。巡礼专用图片导入与压缩流程尚待接入，本目录本身不改变仓库现有提交和归档规则。
