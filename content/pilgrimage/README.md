# 日本旅行与巡礼素材

原素材按“行程／城市／作品或主题记录”整理；东京等大城市允许增加片区层级，普通旅行与作品巡礼同层收录。现有文件夹不为网页展示强制改名，图片保留原文件名。

示例结构：

    行程名称/
      千叶/
        春物/
          地点图片.jpg
          说明.txt（可选）
      东京/
        池袋/
          MYGO & MUJICA/
            地点图片.jpg
      行程来源说明.txt

城市、作品、地点已有文件名标记时，不要求逐张写说明。别称、背景、出处或感想可补充在说明中；没有精确坐标、日期、集数或时间点时不补猜。已经拼好的作品／现实对照图保持完整，不拆分重拼。

正式配置在 content/pilgrimage/records.json；图片按配置分组自动扫描，构建生成 assets/generated/japan-travel/manifest.json。新图片加入已有分组可自动纳入；新增行程、城市或主题分组须一并登记配置，否则缺图或未登记图片会明确报错。

本批2026年8月13—21日东京及周边旅行按用户2026-11-16明确要求保留原尺寸、原质量，不压缩、不缩放。生成脚本制作与原图字节／SHA-256 一致的发布副本，正文按需加载，超大像素照片通过原图入口查看。其他媒体仍按原预览规则处理，本次未迁移原件归档政策。

提交GitHub时包含原素材与来源说明、records.json、页面和生成脚本；assets/generated/ 与 _site/ 是自动构建产物，不需要提交。详细流程见 docs/pilgrimage.md。
